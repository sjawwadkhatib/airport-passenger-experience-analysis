# ✈️ Airport Passenger Experience Analysis

## About This Project

This project is based on the quantitative research conducted for my Master's thesis in Aviation Management at Bahçeşehir University, Istanbul.

The original research examined how **self-service technologies (SSTs) influence passenger satisfaction at airports**, focusing on factors such as ease of use, time saving, reliability, convenience, and passenger assistance.

## 🎯 Research Objective

To explore passengers' experiences with airport self-service technologies and understand the factors associated with their overall satisfaction and future preference for using these technologies.

## 📊 Dataset

The study collected **80 valid survey responses** from air passengers.

The dataset includes variables related to:

- Age group
- Travel frequency
- Self-service technologies used
- Ease of use
- Time saving
- Reliability
- Need for assistance
- Overall satisfaction
- Future preference
- Passenger suggestions

## 🔍 Analysis

This repository will document the data-analysis process, including:

- Data cleaning and preparation
- Descriptive statistics
- Passenger characteristics
- Analysis of SST experience and satisfaction
- Relationships between key variables
- Data visualizations
- Interpretation of findings

## 🔒 Data Availability

The respondent-level dataset is not publicly included in this repository. The anonymized data may be made available upon reasonable request, subject to the ethical conditions applicable to the original study.

## 🛠️ Tools

Analysis will be conducted using **Python**, with appropriate data-analysis and visualization libraries.
